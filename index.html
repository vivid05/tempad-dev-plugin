🎨 TemPad Dev 插件集

两个样式转换插件：H5（Stylus / CSS）与 React Native。TemPad Dev 一次只加载一个，按项目切换地址即可。

📦 Timo UI —— H5 项目

https://vivid05.github.io/tempad-dev-plugin/dist/plugin.mjs

📦 Timo RN —— rn-store 仓库

https://vivid05.github.io/tempad-dev-plugin/dist/plugin-rn.mjs

✨ 功能特性

Font 块 (SCSS)

自动组合字体属性为 @include font(...) 格式，无字体属性时显示"无"

Style 块 (CSS)

智能转换 fill → background-color，组合 stroke 为 border，自动过滤不需要的属性

RN Style 块 (Timo RN)

Figma CSS → React Native StyleSheet：750 稿尺寸包 s()，左右方向转 start/end 适配阿语， line-height: 120% 按字号换算，box-shadow 拆成 iOS shadow* + 安卓 elevation， 渐变 / 毛玻璃 / grid 等 RN 不支持的转成 // ⚠ 提示
